# daengle_design

댕글 앱에서 사용하는 재사용 가능한 Flutter UI 패키지입니다.

```dart
import 'package:daengle_design/daengle_design.dart';
```

테마 `DaengleTheme.light()`, 버튼 `DsButton`/`DsAsyncButton`, 고정 제목 입력 `DsTextField`/`DsSelectField`/`DsDateField`, 선택 `DsChip`/`DsWeekdayPicker`, 레이아웃 `DsPage`/`DsField`/`DsPanel` 등을 제공합니다. 공개 API는 `lib/daengle_design.dart`에서 확인할 수 있습니다.

Pretendard 폰트와 라이선스는 `assets/fonts/`에 포함되어 있습니다.

```sh
flutter pub get
flutter test
```
